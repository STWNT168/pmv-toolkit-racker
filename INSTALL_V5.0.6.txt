FEATURES:
- SPM Office is loaded from USER_MASTER and locked.
- SPM duplicate submission for the same date is blocked atomically.
- SPM can delete today's own entry and submit a corrected entry.
- Historical duplicate DAILY_DATA rows can be cleaned safely.
- Admin dashboard shows updated SPM count, pending SPM count, completion progress, office-wise figures and detailed SPM status.
- Dashboard reads DAILY_DATA and logically deduplicates SPM/date records.
